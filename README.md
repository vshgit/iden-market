# Айден Маркет — демо

Кликабельное демо маркетплейса техники Apple для обсуждения продукта с Айденом. Не MVP: без бэкенда, оплата, доставка и проверка IMEI понарошку.

- `index.html` — вся витрина, кабинет продавца и бэк-офис в одной странице; данные лотов встроены, состояние хранится в браузере.
- `ph/` — фото лотов из каталога миниаппа (по 6 кадров на лот в одном файле).
- `ref/` — эталонные фото моделей с сайта Apple, только для демо.

Сверху переключатель ролей и кнопка «Сценарий» со сквозной цепочкой из 6 шагов.
